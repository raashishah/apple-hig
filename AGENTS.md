# Agent rules

## Subagent models

Any subagent or helper you start (explore, Task, pstack helpers such as /how or /arena, etc.) must use grok-4.7 with fast off. Medium effort by default. High for hard debugging, migrations, and the hardest-tasks, arena, and architect roles. xhigh only when the person launching it asks for it for a big multi-part plan and states why, never as a file default, and never for audit or design work. Fast is always off. Never composer or any fast model. If you can't set the model, do that work yourself.
